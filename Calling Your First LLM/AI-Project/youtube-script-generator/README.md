# Calling Your First LLM

YouTube script generator using OpenAI, Gemini and Claude together.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync
cp .env.example .env    # then add your own API key
```

## Files

- `prompts.py`

Run any file on its own:

```bash
uv run prompts.py
```
