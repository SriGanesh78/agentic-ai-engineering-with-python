# Building a Complete RAG Application 04-10-2026

A complete RAG application: hybrid search, metadata filtering, reranking and corrective RAG.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync
cp .env.example .env    # then add your own API key
```
