# Getting Started with LangChain  23-08-2026

Talking to LLM.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync
cp .env.example .env    # then add your own API key
```

## Files

- `telusko-app1.py`
- `telusko-app2.py`
- `telusko-lc.py`
- `telusko-lcm.py`

Run any file on its own:

```bash
uv run telusko-app1.py
```
