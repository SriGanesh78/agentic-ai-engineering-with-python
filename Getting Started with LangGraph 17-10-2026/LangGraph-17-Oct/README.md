# Getting Started with LangGraph 17-10-2026

Getting started with LangGraph: state, nodes and edges.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync   # resolves the latest matching versions
cp .env.example .env    # then add your own API key
```

## Files

- `1_suggest_destination.py`
- `2_joke_suggestion.py`
- `3_destination_itinerary.py`
- `4_recipe_shopping_list.py`
- `5_app_sentimental_reply.py`

Run any file on its own:

```bash
uv run 1_suggest_destination.py
```
