# MCP (Part - 2) 13-09-2026

MCP server with FastMCP and a LangChain client.

Class source code for the **Agentic AI Engineering with Python** course.

## Setup

```bash
uv sync   # resolves the latest matching versions
cp .env.example .env    # then add your own API key
```

## Files

- `my_mcp_client.py`
- `my_mcp_server.py`

Run any file on its own:

```bash
uv run my_mcp_client.py
```
